# מעקב פרויקטים – אפליקציית אנדרואיד

## איך מקבלים קובץ APK (בלי להתקין כלום במחשב)

1. נכנסים ל-github.com ופותחים חשבון חינמי.
2. לוחצים על + ואז על New repository, נותנים שם (למשל project-tracker) ולוחצים Create repository.
3. בעמוד שנפתח לוחצים על "uploading an existing file" וגוררים לשם את כל התוכן של התיקייה הזו, כולל התיקייה ‎.github. לוחצים Commit changes.
4. עוברים ללשונית Actions. הבנייה מתחילה לבד ולוקחת כ-5 דקות. כשמופיע וי ירוק, לוחצים על הריצה.
5. למטה, תחת Artifacts, מורידים את project-tracker-apk. זה קובץ zip ובתוכו app-debug.apk.
6. מעבירים את הקובץ לטלפון, פותחים אותו ומאשרים "התקנה ממקורות לא ידועים".

אם בלשונית Actions לא מופיע כלום, התיקייה ‎.github לא עלתה. במקרה כזה:
Actions → set up a workflow yourself, מדביקים את התוכן של ‎.github/workflows/build.yml ולוחצים Commit.

## הגדרת המייל האוטומטי (פעם אחת)

1. בחשבון Google של כתובת השולח מפעילים אימות דו-שלבי (myaccount.google.com → אבטחה).
2. נכנסים ל-myaccount.google.com/apppasswords, יוצרים סיסמת אפליקציה בשם "מעקב פרויקטים" ומעתיקים את 16 התווים.
3. באפליקציה: הגדרות → מזינים את כתובת ה-Gmail, את סיסמת האפליקציה ואת הנמענים, ומפעילים "שליחה אוטומטית".
4. לוחצים "שליחת מייל בדיקה עכשיו". תוך דקה תקפוץ התראה אם המייל נשלח או מה השתבש.

הסיסמה נשמרת מוצפנת בטלפון בלבד.

## מה האפליקציה עושה לבד
- פעם ביום, אחרי השעה שנבחרה בהגדרות: התראה על כל המשימות הפתוחות ועל שלבים שלא בוצעו תוך 7 ימי עבודה (ראשון–חמישי).
- פעם ביום, אחרי שעת המייל: סיכום של כל המשימות הפתוחות והשלבים שבביצוע, בכל הפרויקטים, לכל הנמענים.
- אם הטלפון היה בלי אינטרנט, המייל יישלח בשעה שאחרי שהחיבור יחזור.

הנתונים נשמרים בטלפון. מחיקת האפליקציה מוחקת אותם, אז כדאי לייצא לאקסל מדי פעם.

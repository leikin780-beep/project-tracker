# מעקב פרויקטים – בניית APK

כל הקבצים כאן נמצאים בתיקייה אחת, בלי תת-תיקיות, כך שאפשר להעלות אותם ל-GitHub גם מהטלפון.

1. ב-repository ב-GitHub: Add file → Upload files, בוחרים את כל הקבצים מהתיקייה הזו ולוחצים Commit changes.
2. פותחים את הקובץ ‎.github/workflows/main.yml, לוחצים על העיפרון (Edit), מוחקים את כל התוכן ומדביקים את התוכן של build-apk.yml. לוחצים Commit changes.
3. ב-Actions מחכים לווי ירוק, ומורידים את project-tracker-apk תחת Artifacts.

## הגדרת המייל האוטומטי (פעם אחת)
1. בחשבון Google של השולח מפעילים אימות דו-שלבי.
2. ב-myaccount.google.com/apppasswords יוצרים סיסמת אפליקציה ומעתיקים את 16 התווים.
3. באפליקציה: הגדרות → כתובת Gmail, סיסמת אפליקציה, נמענים, ומפעילים "שליחה אוטומטית".
4. "שליחת מייל בדיקה עכשיו" – תוך דקה תגיע התראה אם המייל נשלח.
